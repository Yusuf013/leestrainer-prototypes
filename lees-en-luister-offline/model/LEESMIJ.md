# Spraakmodel (optioneel)

Zet hier `vosk-model-small-nl-0.22.zip` neer (±40 MB, Apache 2.0-licentie).
Dan laadt de pagina het model van je eigen website, in plaats van van Hugging Face.
Dat is handig als het schoolnetwerk Hugging Face blokkeert.

Downloaden kan via https://alphacephei.com/vosk/models
of via https://huggingface.co/rhasspy/vosk-models/tree/main/nl
